## About

I'm a product engineer finishing a **B.Tech in AI & ML** at Chinmaya Vishwa Vidyapeeth (class of 2027), based in Kochi. I build things end to end, from the database schema to the last screen, and I don't call a project done until it's deployed.

- **Shipping:** 14 public repos since March 2026, five of them live on Vercel
- **Experience:** AI & ML intern at **Litmus7**, Infopark: React front end for a retail promotions analyzer, plus a LangGraph ReAct agent with a Qdrant RAG pipeline. ML intern at **Cognifyz**: classification, recommendation and geospatial analysis
- **Building:** an offline capsize detector for Kerala fishing boats
- **Looking for:** internships and junior product-engineering roles
